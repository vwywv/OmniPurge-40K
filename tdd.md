name: tdd
description: Execute a strict Test-Driven Development (TDD) loop.

When following TDD, you must STRICTLY follow the Red-Green-Refactor cycle:
1. Red: Write a failing test for the intended behavior. Do NOT write the implementation yet.
2. Green: Write just enough implementation code to make the test pass.
3. Refactor: Clean up the code and optimize it while ensuring the test stays green.

Never write implementation code before writing the corresponding test.
